**BRIT CONNECT NETWORK OUTAGE PROJECT OVERVIEW**

This project was designed to develop a comprehensive data analytics solution that enables BritConnect to monitor network outages, analyze root causes, and improve overall service reliability through centralized reporting and actionable insights.

The primary objective was to build a centralized outage analytics database using Microsoft SQL Server. This repository would consolidate outage incidents, network alarms, site inventories, customer impact estimates, trouble tickets, maintenance records, vendor information, and SLA data into a unified data model.

A second objective focused on measuring network performance through key metrics such as outage duration, affected sites, affected customers, service downtime, outage frequency, and regional availability.

The project also aimed to identify leading outage drivers by analyzing incidents across root cause categories, network layers, technologies, vendors, regions, and site types.

Additional objectives included improving Mean Time to Detect (MTTD) and Mean Time to Repair (MTTR) through incident lifecycle analysis, identifying recurring problem sites and network assets, monitoring SLA compliance, and evaluating vendor performance.

The final objective was to deliver interactive Power BI dashboards tailored to executives, NOC analysts, engineers, vendor managers, and customer-impact stakeholders, enabling proactive operational management and informed strategic decision-making.

**HORIZON HEALTHCARE PROJECT OBJECTIVE**

This Microsoft SQL Server (MS SQL) project focuses on the structured analysis of historical and current bed demand and occupancy across Horizon Health Network hospitals.

The project involves consolidating healthcare data, performing exploratory analysis, and preparing meaningful insights that can support operational decision-making. The analysis focuses on understanding patterns in bed demand, occupancy levels, and capacity utilisation across hospitals and wards.

The project demonstrates how SQL-based data analysis can transform fragmented operational data into consistent and actionable information for healthcare planning.

**Industry Relevance**

Hospital bed capacity is a critical and limited healthcare resource. Effective analysis of occupancy and demand can help healthcare organisations identify pressure points, understand utilisation patterns, and make better decisions about the allocation of available beds.

**Key Strategic Drivers**

Efficiency: Identify emerging bed pressure across hospitals and wards more quickly.
Decision-Making: Provide consistent, consolidated insights instead of relying on fragmented manual reporting.
Cost Management: Improve visibility of capacity requirements and help reduce avoidable overtime and agency staffing.
Optimisation: Support more effective utilisation of existing bed capacity across specialties.
Evidence-Based Planning: Encourage data-driven decision-making within hospital bed management teams.

**Strategic Outcome**

The goal of the project is to provide hospital planners with consistent and trustworthy visibility into bed demand and occupancy patterns.

By using structured SQL analysis rather than predictive modelling, the project supports earlier identification of operational pressures, better capacity planning, fewer disruptions, and more confident healthcare management decisions.
