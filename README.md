**BRIT CONNECT NETWORK OUTAGE PROJECT OVERVIEW**

This project was designed to develop a comprehensive data analytics solution that enables BritConnect to monitor network outages, analyze root causes, and improve overall service reliability through centralized reporting and actionable insights.

The primary objective was to build a centralized outage analytics database using Microsoft SQL Server. This repository would consolidate outage incidents, network alarms, site inventories, customer impact estimates, trouble tickets, maintenance records, vendor information, and SLA data into a unified data model.

A second objective focused on measuring network performance through key metrics such as outage duration, affected sites, affected customers, service downtime, outage frequency, and regional availability.

The project also aimed to identify leading outage drivers by analyzing incidents across root cause categories, network layers, technologies, vendors, regions, and site types.

Additional objectives included improving Mean Time to Detect (MTTD) and Mean Time to Repair (MTTR) through incident lifecycle analysis, identifying recurring problem sites and network assets, monitoring SLA compliance, and evaluating vendor performance.

The final objective was to deliver interactive Power BI dashboards tailored to executives, NOC analysts, engineers, vendor managers, and customer-impact stakeholders, enabling proactive operational management and informed strategic decision-making.
